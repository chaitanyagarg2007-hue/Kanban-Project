# Kanban Project

A responsive Kanban task management board built using HTML, CSS, and JavaScript. It helps users organize tasks, track their progress, and manage their workflow through a simple and interactive interface.

## Features

- **Task Management:** Create and delete tasks easily.
- **Three Workflow Columns:** Organize tasks according to their progress.
- **Drag and Drop:** Move tasks between columns to update their status.
- **Live Task Counts:** Track the number of tasks in each column.
- **Local Storage:** Preserve tasks across page refreshes.
- **Dark/Light Theme:** Switch between themes for a personalized experience.
- **Responsive Design:** Use the board across different screen sizes.

## Tech Stack

- HTML5 — Page structure
- CSS3 — Styling, layout, and responsive design
- JavaScript (Vanilla JS) — DOM manipulation, event handling, drag-and-drop interactions, and local storage

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/chaitanyagarg2007-hue/Kanban-Project.git
```

### 2. Navigate to the project directory

```bash
cd Kanban-Project
```

### 3. Run the project

Open `index.html` in your browser, or use the Live Server extension in VS Code.

No additional dependencies or build tools are required.
